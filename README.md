# Harry Potter Invisibility Cloak

> **Hogwarts called. I answered with OpenCV.**

A real-time **Harry Potter-style Invisibility Cloak** built using **Python + OpenCV**.

The project detects a dark brown cloth using **HSV color masking** and replaces it with a captured background to create the invisibility effect. ✨

## 🚀 Features

- Real-time webcam processing
- HSV color detection
- Background replacement
- Mask refinement using morphological operations
- Video recording

## 🛠️ Tech Stack

- Python
- OpenCV
- NumPy
